Как подключить 404.html

GitHub Pages, Cloudflare Pages, NetlifyПоложите файл в корень сайта под именем 404.html. Больше ничего не нужно.
VercelФайл 404.html в папке public (или в корне статического проекта).
nginxДобавьте в конфиг сервера, нажмите, чтобы скопировать:error_page 404 /404.html;
Apache (.htaccess)Нажмите, чтобы скопировать:ErrorDocument 404 /404.html
ExpressПосле всех маршрутов:app.use((req, res) => res.status(404).sendFile(__dirname + "/404.html"));

Файл самодостаточный: стили и иллюстрация внутри, внешних запросов нет.
